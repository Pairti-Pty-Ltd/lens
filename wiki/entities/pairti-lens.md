# Pairti Lens

Lens gives people a place to read, review, and publish work in a shared Git checkout. Several projects can stay open together. A local agent can read a selected passage, including unsaved changes, and return an edit to the same buffer.

Use the [north stars](../../doc/concept.md) for product decisions and the [README](../../README.md) to install Lens or serve a library.
